- 2026-07-10 (REV-021, PLAN-2026-W28-N wave W4): qa's BUG-021 (critical — `PROMPTS_BASE_DIR` unset-only auto-correction guard silently bypassed by an explicitly-set-but-wrong relative `.env` value, all 4 prompt-driven agents silently degrade to generic fallback prompts) cited only the merge worktree (`/tmp/wt-f1-stt-ocr-integration`) as evidence. Independently grepped the same guard pattern in the **main repo's own current Master tree** (`apps/ai-server/src/{f1.py,f2.py,safety_matrix.py,continuous_test.py}`, byte-identical code/line pattern) and, critically, the **main repo's own live `apps/ai-server/.env`** — found it already carries the identical broken relative value `PROMPTS_BASE_DIR=docs/ai/prompts`. This is stronger evidence than the filing agent's own repro (which only showed the worktree) that the defect's mechanism *and* trigger both predate the branch/merge under review — decisive for ruling it NOT PR-gating (the defect isn't introduced by the diff being reviewed) while still requiring prominent, unsoftened disclosure (it's a real, critical, standing project defect).

**Why:** A "this predates X" claim is only as strong as what it was checked against. A worktree-only repro leaves open whether the worktree itself introduced the triggering condition (e.g., a locally-edited `.env` unique to that checkout). Checking the *main* repo's own current state directly (not just trusting the filing agent's framing) either confirms the claim more strongly (as here) or reveals the claim was worktree-specific and should not be excused as pre-existing.

**How to apply:** Whenever adjudicating whether a finding is "introduced by this change" vs. "pre-existing," and tool access permits (Read/Grep on the actual main-tree files, not just the branch/worktree under review), independently re-derive the "predates" claim against the main tree's own current code AND config/env files (redacting secret *values*, only checking key presence/non-secret value patterns) rather than accepting the filing agent's own repro scope. This is cheap (a few greps) and can materially change a REV's gating verdict.
