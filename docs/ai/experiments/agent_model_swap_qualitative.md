# NeuroSync LLM 조합 — 정성 평가 (대화 품질)

> 정량(지연·완주)에 이어, **대화 에이전트(dialogue)를 Solar/EXAONE/A.X로 교체**했을 때
> AI 발화가 실제로 **자연스러운지·어색한지·문진을 제대로 이끄는지**를 실 대화 로그로 평가.
> 브랜치 `test/agent-model-swap-benchmark` · RAG DB 연동 · F1~F5 라이브.

## 평가 설계
- **비교 대상**: `solar_baseline`(dialogue=Solar) · `exaone_dialogue`(dialogue=EXAONE) · `ax_dialogue`(dialogue=A.X). dialogue 외 에이전트는 전부 Solar로 고정 → **대화 에이전트만 교체**.
- **조건**: VP-001, 2세션(14일 간격), 각 4턴. 매 턴 AI 응답 텍스트를 로그로 캡처(`/tmp/qual_logs/*.log`).
- **⚠️ 통제 수준(중요)**: 구성/설정(페르소나·세션·턴·k·간격·DB·dialogue 외 전 에이전트=Solar·환자 시뮬레이터 모델)은 **세 실행 모두 동일**하다. 그러나 **환자 발화 자체는 동일하지 않다.** F1의 환자는 대본이 아니라 **LLM 시뮬레이터**(`tests/simulation/patient_llm.py::PatientLLM`, `temperature=0.7`, **시드 없음**)이며, AI가 던진 질문에 **반응**해 답을 생성한다. 따라서 (a) 매 실행 비결정적이고 (b) 각 모델의 질문에 따라 **대화 경로가 갈린다**. (`--answer-mode expected`는 F3 설문 문항 점수에만 적용, F1 대화와 무관.) → **아래 수치는 통제된 A/B가 아니라 서로 다른 대화 경로 위의 관찰**임에 유의.
- **평가 축**: ① 자연스러움/공감 ② **문진 진행력**(다음 질문 유도) ③ 맥락 유지(세션 간 연속성) ④ **출력 안정성**(깨진 응답·형식 누출) ⑤ 임상 어투 적절성.
- **발견의 견고성 구분**: ④ 출력 안정성(빈 응답·JSON 누출)은 **입력과 무관**하게 재현되는 진짜 결함 → 견고. ②의 질문 횟수 수치는 **경로 의존** → 경향 참고용(엄밀 비교엔 아래 "통제 재검" 필요).

### ⚑ 핵심 정정 — A.X "질문 안 함"은 **경로 artifact였다**
- 앞선 비통제 실행에서 A.X가 "8턴 내내 질문 0회"였던 건 **모델 특성이 아니라** 그때 LLM 환자가 정보를 먼저 쏟아내 대화 경로가 갈렸기 때문. **동일 입력에서 A.X는 매 턴 스크리닝 질문을 정확히 던진다:**
```
환자: 요즘 잠이 안 오고 불안해서 힘들어요. 회사 집중도 안 되고 실수도 늘어요.
A.X:  요즘 잠이 안 오고 불안해서 많이 힘드셨겠어요.
      혹시 최근 들어 스스로 해치고 싶다는 생각이나 죽고 싶다는 생각이 드신 적이 있으신가요?  ← SI 선별
환자: 약도 안 먹고 병원도 안 가요. 몸도 마음도 이상한 느낌이에요.
A.X:  몸도 마음도 이상한 느낌이 들어 많이 불안하셨을 것 같아요.
      혹시 최근 진단받으신 신체질환이나, 새로 복용 중이거나 변경된 약이 있으신가요?  ← 복약력
```
- 오히려 통제 조건에선 **A.X가 가장 깔끔**하다: "공감 한 줄 + 줄바꿈 + 질문 한 줄" 구조가 5턴 일관, 반복·재시도 0.

### Solar — 여전히 견고하나 이 스크립트에선 **질문 반복**이 보임
```
T3: …일상생활에 어떤 구체적인 어려움이 가장 크게 다가오는지 편하게 말씀해 주실 수 있나요?  (retry=2)
T4: 잠 못 자고 예민해져서 회사 생활에까지 영향을 미치고 계시는군요. 그런 상태가 지속되면서
    일상생활에 어떤 구체적인 어려움이…  ← T3 질문을 거의 그대로 반복
```
- SI 선별을 T1에 즉시 배치하는 등 커버리지·판단은 양호하나, 같은 스크립트를 반복 입력받자 **동일 질문 재활용**이 관찰됨(near-dup). 통제 조건이 Solar의 반복 성향을 드러냄.

### EXAONE — 문장력은 최상급이나 **출력 결함이 통제 조건에서도 재현**
정상 턴(T0·T3·T4)은 오히려 셋 중 가장 공감·정보량이 풍부하다. 그러나 5턴 중 2턴에서 결함:
```
T1: …혹시 최근에 스스로를 해치고 싶거나, 죽고 싶다는 생각이 드신 적 있으신가요? 안전
    이런 감정이나 싶으신지, 아니면 최근에 특별히 걱정되는 생각이나 싶으신지 여쭤보고 싶어요.
    ← "안전"에서 끊기고 "이런 감정이나 싶으신지" 등 문법 붕괴(비문). 위기 스크리닝 문장이 깨짐
T2: (빈 응답 — 환자에게 아무 말도 생성 못 함)
```
- **동일 입력에서도 빈 응답 1 + 문법 붕괴 1** → 앞선 비통제 실행의 "빈 응답·JSON 누출"이 **경로 artifact가 아니라 실제 모델 결함**임이 통제로 확정. (이번엔 JSON 원문 누출은 재현 안 됨, 대신 빈 응답+비문.)
- 위기 스크리닝(SI) 문장이 하필 T1에서 깨진 점은 **안전상 특히 위험**한 실패 양상.

#### ⚑ (중요) EXAONE 통제 실행이 처음 26회 403 났던 진짜 원인 = **하네스 버그, Friendli 불안정 아님**
- 이전 판단("간헐적 Friendli 403")은 **오진**이었다. 실제 원인: 변형 레지스트리가 EXAONE model을 `${LG_K_EXAONE_ENDPOINT_ID}` **env 플레이스홀더**로 두는데(Solar/A.X는 리터럴 `solar-pro3`/`A.X-K1`), `ModelRouter._resolve_env_vars`는 이를 **os.environ에서만** 확장한다.
- 독립 하네스가 `load_dotenv()`를 호출하지 않아 os.environ에 값이 없었고 → `selection.model_id`가 리터럴 `'${LG_K_EXAONE_ENDPOINT_ID}'` 그대로 Friendli로 전송 → **결정적(간헐 아님) 403 Forbidden**. Solar/A.X는 리터럴이라 무관하게 성공했던 것.
- **수정**: 하네스 상단에서 `load_dotenv(.env)` 호출 → model_id가 `depmkuykpfon9lg`로 정상 확장 → 403 0회로 즉시 해결. (앱 정상 경로인 `continuous_test`는 원래 `load_dotenv()`를 호출하므로 이 버그 없음 — 순전히 임시 하네스 문제.)

### 통제 재검 종합
1. **A.X 재평가**: 통제 조건에서 **질문 유도 5/5·구조 최상·출력 결함 0** → 이전 "문진 미진행" 결론 **철회**. 셋 중 가장 안정적·간결. dialogue 유력 후보.
2. **Solar**: 견고하고 커버리지 좋으나, 이 스크립트에서 **T3≈T4 질문 반복(near-dup)·retry** 노출 → 반복 억제가 개선 포인트. 다소 장황.
3. **EXAONE**: 문장력 최상급이나 **출력 안정성 결함(빈 응답·비문)이 통제에서도 2/5 재현** → dialogue 투입 리스크 확정. json_object 출력 가드 강화 전엔 보류.
4. **방법론 교훈 ①**: 비통제(LLM 환자) 질문-횟수 지표는 신뢰 불가 — 정성 비교는 **입력 고정 후**(A.X 평가가 정반대로 뒤집힘).
5. **방법론 교훈 ②**: 실험 인프라 자체를 의심하라 — "모델/서비스 문제"로 보였던 403이 실은 **하네스 env 로딩 누락**이었다. 리터럴 model_id(Solar/A.X)만 통과하고 env-치환 model_id(EXAONE)만 실패한 비대칭이 단서였음.

## 1. Solar (기준) — 공감 + 진행 균형, 전 턴 안정

발화마다 **환자 말을 반영(mirroring) → 다음 스크리닝 질문**의 2단 구조가 일관됨. 8턴 중 **6턴에서 질문**.

```
환자: 요즘 잠이 잘 안 자고 불안해서 힘들어요. 회사에서 집중도 안 되고 실수도 늘어서 걱정이에요.
Solar: 요즘 잠도 잘 안 오고 불안해서 회사 생활도 힘드시겠어요. 혹시 이전에 정신건강의학과
       진료를 받아보신 적이 있으신가요? 아니면 심리상담을 받아보신 경험이 있으신가요?
```
- 세션 2에서 **맥락 연속성** 뚜렷: *"지난번에도 말씀하셨던 것처럼 잠 못 이루고 불안한 상태가 계속되시는군요."*
- 세션 2 turn 1~2는 질문 없이 공감만 하는 턴도 있으나(경청 강화), 이후 자연스럽게 질문 복귀 → **의도된 완급**으로 읽힘.
- ▶ 약점: 거의 없음. 굳이 꼽으면 반영 문장이 길어 다소 장황할 때가 있음.

## 2. EXAONE — 문장은 풍부하나 **출력 붕괴**가 치명적

정상 작동 시엔 오히려 감정 탐색형 질문까지 얹어 **가장 풍부**하다:
```
환자: 잠을 잘 못 자는 게 제일 힘들어요. 누우면 생각이 많아져서 뒤척이고 새벽에도 깨요.
EXAONE: 잠을 자려고 하면 머릿속이 시끄러워서 한참 뒤척이고, 새벽에도 자주 깨시는 게
        정말 힘드셨겠어요. 그 생각이 머릿속을 맴돌면서 잠을 설치게 만드는 기분이 어떤가요?
```
그러나 **세션 2에서 응답이 두 번 깨졌다**:
```
Turn 2 | AI (reply):                    ← 빈 응답(공백). 환자에게 아무 말도 못 함
Turn 3 | AI (reply): [{"role": "user", "content": "아니요, 정신과나 상담을 받아본 적은 없어요..."}]
                                          ← 대화 히스토리 JSON 원문이 그대로 환자에게 노출
```
- 이건 단순 어색함이 아니라 **환자가 시스템 내부 자료구조(JSON)를 보게 되는 노출 사고**.
- 텔레메트리에도 `near_dup_back_to_back` / `exact_repeat` **가드 위반→재시도**가 찍힘(같은 말 반복 경향).
- 정량 결과의 EXAONE tail 폭증·repair 다발과 **동일 원인**(구조화·반복 억제 취약)이 대화 품질에서도 드러남.
- ▶ 결론: 잘 될 땐 최상급 문장, 그러나 **한 세션에 1회꼴로 붕괴** → 실사용 환자 대면 불가 수준의 리스크.

## 3. A.X — 따뜻하지만 **질문을 안 해 문진이 안 나아감**

> ⚠️ **이 절의 결론은 위 "통제 재검(A)"에서 철회됨.** 아래 "질문 0회"는 비통제(LLM 환자)
> 대화 경로 artifact였고, **동일 입력에서는 A.X도 매 턴 질문을 던진다.** 기록 보존용으로 남김.

8턴 **전부 공감/validation 한 문장, 질문은 0회**:
```
환자: 요즘 잠을 잘 못 자서 힘들어요. 새벽에 깨고 아침엔 집중도 안 되고 실수도 늘어요.
```

## 종합 결론 (통제 재검 반영 — 갱신본)
> ⚠️ 아래 1~4는 **비통제 실행 기준 최초 결론**이며, 2·3은 위 "통제 재검(A)"에서 **수정됨**. 최신 판단은 "통제 재검 종합" 및 5~7 참조.
1. **정량 완주율(3/3 완주)만 보면 안 된다.** 대화 품질은 조건·모델별로 갈린다.
2. ~~dialogue는 Solar 유지가 안전, A.X는 문진 진행 실패~~ → **수정**: 통제 조건에서 A.X는 질문 5/5로 문진을 정상 진행. "문진 실패"는 경로 artifact였음.
3. ~~`mix_optimal`(dialogue=A.X) 재검토 필요~~ → **완화**: A.X dialogue는 통제상 경쟁력 확인. 다만 비통제에서 경로에 따라 수동적이 될 여지가 있어 **다중 페르소나 재현으로 확정** 필요.

## 한계 및 통제 재검 필요
- **환자 입력 비통제(가장 큰 한계)**: 환자가 LLM 시뮬레이터(temp 0.7, 시드 없음, AI 질문에 반응)라 세 실행의 환자 발화가 서로 달랐다. 질문 횟수(6/4/0) 같은 미세 수치는 **동일 입력 위의 통제 비교가 아니다.**
  - **통제 재검 방법**: 고정 대화 스크립트를 replay(`--start-from-conversation`로 동일 환자 턴 주입)하거나, 환자 시뮬레이터에 고정 시드/스크립트를 적용해 **세 모델에 byte-identical 환자 발화**를 먹인 뒤 AI 표현만 비교. 이때 비로소 질문 유도·어색함을 1:1 통제 비교 가능.
- **EXAONE 출력 붕괴는 입력과 무관**하게 재현되므로 통제 재검과 별개로 유효한 결함.
- VP-001 단일 페르소나·2세션·4턴 소표본 — EXAONE 붕괴 빈도(세션당 ~1회)·A.X 질문 회피 경향은 더 큰 표본으로 재확인 권장.
- 본 평가는 **대화 자연스러움/진행력** 중심. 위기 감지 정확도·리포트 정합성은 별도 품질 라운드 대상.
