# 핸드오프 리포트 설계 — 레이아웃 구성 & 데이터 표현

> 대상: `docs/ai/handoff_template/`의 Editorial Clinical Handoff 리포트.
> 목적: **레이아웃을 어떻게 구성했고, 데이터를 어떻게 표현했는지** 정리.
> 데이터 필드 대응은 [`HANDOFF_DATA_CATALOG.md`](./HANDOFF_DATA_CATALOG.md), 편성 원칙은
> [`clinical_handoff_report_content_guideline.md`](./clinical_handoff_report_content_guideline.md) 참조.

---

## 1. 산출 방식 (파이프라인)

```
F1~F5 산출물(temporal.json + handoff.md)
   └─ build_report_json.py  → report JSON (고정 스키마 데이터 계약)
   └─ make_charts.py        → FIG.01/02/03 PNG (trend_plotter.py 엔진)
index.html (고정 레이아웃) + render-report.js (JSON→슬롯 주입)
   └─ Chrome --headless --print-to-pdf  → A4 PDF
```

- **고정 레이아웃 + 값만 주입**: HTML 구조·CSS는 불변, `render-report.js`가 report JSON을
  각 요소 ID(`#p1-metrics`, `#p5-scale` …)에 바인딩. 데이터가 바뀌어도 양식은 그대로.
- **연속 흐름(continuous flow)**: 섹션을 페이지에 고정하지 않고 흐르게 하되, 원자 블록만
  분할 방지(`break-inside: avoid`). 러닝 헤더/푸터·페이지번호는 `@page` 마진박스로 반복.

### 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 8 섹션 스캐폴드(빈 슬롯 ID만) |
| `styles/tokens.css` | 디자인 토큰(색·타이포·치수) |
| `styles/layout.css` | 그리드·컬럼 |
| `styles/components.css` | 카드·표·타임라인·차트블록 등 컴포넌트 |
| `styles/print.css` | A4 `@page`, 러닝 헤더/푸터, break 규칙 |
| `scripts/render-report.js` | JSON → DOM 바인딩 |
| `scripts/build_report_json.py` | F1~F5 → report JSON 변환 |
| `scripts/make_charts.py` | 종단 차트 렌더(trend_plotter 어댑터) |

## 2. 디자인 토큰 (편집 디자인 언어)

### 색 (Petrol Teal + Ink + Clay)
| 토큰 | 값 | 용도 |
|---|---|---|
| `--primary` | `#17494E` Deep Petrol Teal | 주요 데이터·제목·차트 라인 |
| `--ink` | `#17211F` | 본문 |
| `--secondary` | `#5E6A68` cool gray | 메타·라벨·보조 텍스트 |
| `--accent` | `#A6462F` Clay | 섹션 번호·우선순위 강조 |
| `--danger` | `#C4302A` | **실제 위험만** (자살문항 양성·고위험) |
| `--success` `--warning` | `#2E6E62` `#A96F18` | 개선/주의 (절제 사용) |
| `--line` `--soft-bg` | `#D5D6D2` `#E9EEEC` | 얇은 구분선·옅은 강조 배경 |
| `--paper` | `#FFFFFF` | 배경(흰색, 차트도 투명 배경으로 합성) |

원칙: 초록을 "개선" 전용으로 남발하지 않음. **빨강은 실제 위험/악화/위험범주 진입에만.**

### 타이포
- 3계열: `--font-serif`(Noto Serif KR, 리포트 대제목), `--font-sans`(Pretendard, 본문·라벨),
  `--font-mono`(수치·회차/일자).
- 스케일: 리포트 제목 26px → 지표 수치 30px → 본문 10px → 섹션 라벨 9px(대문자 트래킹).
- 섹션 라벨은 소형·자간 확대(`letter-spacing`)로 위계 구분, 본문과 명확히 분리.

### 치수
- A4 `210×297mm`, 여백 상 20 / 좌우 17 / 하 15 mm.
- 12컬럼 그리드(`col-7/col-5`, `col-8/col-4`) — 본문 + 우측 레일 구조.

## 4. 데이터 표현 방식 (컴포넌트별)

### 4.1 지표 카드 (현재 상태)
PHQ-9 / 위기단계(CTRS) / AUDIT-C 를 **큰 수치 + 게이지 바** 카드로.
```
PHQ-9          ← 척도명
우울 선별       ← 부제
21 / 27        ← 수치(30px) / 최대
중증 범위       ← 심각도 밴드명
▼1 이전 22      ← 직전값 대비 변화(방향 화살표)
[▓▓▓▒░░░░]     ← 심각도 구간 게이지(clay 농도) + 현재값 마커
9개 문항 합산·각 0–3점 · 현재 21점   ← 척도 근거 캡션
```
- 게이지: 심각도 구간을 clay 농도(옅음→진함)로 배치, 현재값 위치에 마커.
- 존재하는 지표만 카드 생성(음주 데이터 없으면 AUDIT-C 카드 미표시).

### 4.2 위험·안전
- **당해 세션 평가**: 위험평가 문장 + `위기 단계(CTRS) 4/5 · 준안정` + 대표 발화 인용 +
  3필드(자살사고 문항 / 안전 의뢰 / 문진 최신성).
- **안전 플래그**: 색점(level) + 문장. 실제 위험만 `--danger`.
- **위험 신호 경과**: 타임라인(최초·최고·최신 중심으로 압축), 각 항목 `날짜 / Session n / 발화·note`.

### 4.3 임상 요약
- 서사: `주호소 / 현병력 / 정신상태검사`를 라벨+문단으로. MSE는 "텍스트 문진 특성상 관찰 평가 제한" 한 줄.
- 대표 발화 1개(인용 블록).
- 우측 **임상 배경 레일**: 신체질환/정신과 과거력/사회력/가족력 등 — `라벨 · 값 · 회차/일자` 소형 항목.
- 최신 설문 요약: `21/27 · PHQ-9 중증 범위 · 10회차·2027-01-14` + `자살사고 문항(9번) 음성·0점` +
  AUDIT-C 요약. (문항별 점수는 부록으로)

### 4.4 종단 경과 — 텍스트 + 차트
- **주요 세션 타임라인**: 최대 6개(초진·전환점·최신), `날짜 / Session n / 변화 서술 · 척도`.
- **척도 변화 요약**: 지표별 `기준값 → 최신값` + 방향 태그(개선/악화/변화없음) + 범주 변화 노트.
  `개선/악화` 한 단어가 아니라 **지표별 상태**로. from→to에 회차·일자 병기.
- **FIG.01 (임상 종단)**: PHQ-9(+GAD-7/AUDIT-C) 상단 · CTRS 하단 스몰 멀티플. 아래 §5.
- **FIG.02 (보조 지표)**: 정서 극성 sparkline + 문진 충족도 막대. "임상 척도 아님" 명시.
- 각 차트 밑 **축 값 주석** 1줄 + `FIG.0n` 캡션 + 출처.

### 4.5 다음 조치
- 번호형 액션(최대 5): `본문 텍스트` + 메타 `우선 확인 / 담당 정신건강의학과 / 근거 8회차`.
  - 영문 업무 메타(PRIORITY/STATUS/OWNER/SOURCE) 대신 **한글**, STATUS(OPEN/CLOSED) 제거.
  - 우선순위: HIGH→"우선 확인" / MEDIUM→"확인 권장"(색 강조 유지).
- 권장 진료: `진료과 — 사유`. 문서 정보: Report ID·기간·평가일·생성일·데이터 출처.

### 4.6 상세 부록 (연속 흐름으로 본문 뒤 이어붙임)
- **문항별 설문**: PHQ-9 9문항, 각 `문항 · 점 도트(0–3) · 점수`. 9번(자살)은 강조 클래스.
- **AI 참고 지표(비진단)**: 질환 유사도 **순위 스냅샷만**(추세 차트 아님) — `순위 · 질환명 · similarity`.
  "참고·비진단" 명시, `similarity`를 확률처럼 표기하지 않음.
- **전문 인용**: 주호소·현병력 전문(위험 발화는 §위험에 있으므로 제외).
- **슬롯별 전체 변화 이력**: **값이 실제 변한 슬롯만**, 각 회차 `S1 · 2026. 07. 15 · 값` (회차+일자).

## 5. 종단 차트 표현 규칙 (`trend_plotter.py`)

- **스몰 멀티플 + 공유 x축**: 임상 패널(PHQ/GAD/AUDIT/CTRS) 세로 정렬, 날짜 라벨 최하단만.
- **x축**: 세션 **등간격 배치 + 각 위치에 실제 날짜(m/d) 라벨** — 초기 주간 세션이 날짜축에서
  몰려 겹치던 문제 해소, 날짜 정보는 유지, FIG.01·02 x축 정렬.
- **마커·선**: **실측 세션에만 마커(점)**, 미측정 세션은 마커 없이 **관통해 실측점끼리 실선 연결**
  (추세선). 값을 지어내는 보간은 없음.
- **심각도 밴드**: PHQ/GAD 배경에 저채도 clay 음영(위로 갈수록 진함), 우측에 밴드명.
- **CTRS**: 순서형 step(`where="post"`), **1 최긴급(하단) → 5 안정(상단)** (반전 없음), 틱 라벨 병기.
- **정서**: 저높이 sparkline + 0 기준선, "보조 지표·임상 척도 아님".
- **문진 충족도**: 라인 대신 **세션별 막대(트랙+채움)**, "데이터 수집 완성도(임상 상태 아님)".
- **색/배경**: teal/neutral, 빨강은 실제 위험만, 투명 배경, 상·우 spine 제거·얇은 그리드.
- 부록 FIG.03(질환 유사도 추세)는 기본 제거(순위 스냅샷으로 대체).

## 6. 조건부·견고성 규칙

- **존재하는 것만 렌더**: 데이터 없는 지표·섹션은 숨김(AUDIT-C 카드, FIG.03, 빈 슬롯).
- **중복 제거**: 한 정보는 한 주 위치에만. 위험 발화=위험 섹션, 슬롯 최신=임상 요약/레일,
  전체 이력=부록. baseline/latest는 카드·척도요약·차트로 분산하되 재서술 금지.
- **최신성 표기**: 최신 설문이 당해 세션 미시행이면 `직전 시행 · 날짜` 포인터.
- **비노출**: 모델명·프롬프트·파일명·변수명·토큰·latency 등 개발자 정보 0건.
- **비진단 프레이밍**: `similarity`·정서·충족도를 확률/임상 척도로 오인하지 않도록 라벨링,
  말미 면책 1회.

## 7. 요약

- **양식**: A4 편집 디자인(Petrol Teal/Ink/Clay), 8 섹션 연속 흐름, 12컬럼 그리드,
  마스트헤드+러닝 헤더/푸터.
- **데이터 표현**: 수치는 게이지 카드, 배경은 서사+레일, 경과는 타임라인+척도요약+스몰멀티플 차트,
  상세는 부록으로 위계 분리. 실측 세션에만 마커·연결선, 빨강은 실제 위험만.
- **구동**: 고정 레이아웃 + report JSON 값 주입(데이터 계약), F1~F5 → build → charts → PDF.
