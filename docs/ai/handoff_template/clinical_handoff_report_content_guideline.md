# 범용 임상 핸드오프 리포트 편성·축약 가이드

## 1. 문서 목적

이 문서는 대화형 문진, 설문, 위험평가, 종단 분석, 진료과 추천 등 여러 에이전트 또는 데이터 소스에서 생성된 정보를 **임상 인계용 보고서에 어떻게 선별·축약·배치할지** 정리한 범용 가이드다.

핵심 목표는 다음과 같다.

- 다음 담당자가 짧은 시간 안에 현재 상태와 우선 조치를 파악할 수 있도록 한다.
- 동일한 사실이 여러 페이지에서 반복되는 문제를 줄인다.
- 환자 상태, 데이터 품질, AI 참고정보를 서로 다른 위계로 구분한다.
- 기본 임상 보고서와 상세 감사·연구용 부록을 분리한다.
- 고위험 사례와 일반 추적 사례 모두에 적용 가능한 조건부 출력 구조를 만든다.

### 1.1 데이터 소스 및 용어 기준

이 문서는 소스 중립적 **범용** 가이드이지만, NeuroSync 파이프라인에 적용할 때의 실제
필드 대응은 [`HANDOFF_DATA_CATALOG.md`](./HANDOFF_DATA_CATALOG.md)(F1~F5 저장 데이터 전수 +
편성 등급)를 단일 진실 소스로 삼는다. 아래 용어는 그 카탈로그와 일치시킨다.

- **위기 단계(CTRS)**: 1–5 순서형. 1 초응급 · 2 고위험 · 3 급성기 · 4 준안정 · 5 안정.
  값이 **낮을수록 위험**. 그래프는 1 하단 → 5 상단으로 고정(반전 금지).
- **척도 심각도 밴드**: PHQ-9(0–27) 정상0–4/경도5–9/중등도10–14/중등–중증15–19/중증20–27,
  9번=자살 문항 · GAD-7(0–21) 정상0–4/경도5–9/중등도10–14/중증15–21 · AUDIT-C(0–12,
  국제 컷오프 남4·여3).
- **핵심 문진 슬롯**: 8개(주호소·현병력·정신과 과거력·신체병력·개인사회력·가족력·물질사용·
  위험평가) + 관찰 슬롯 1개(정신상태검사). 채움률 분모는 8개.
- **종단 결론 필드(F4)**: `overall_direction`(전체 방향), `course_shape`(경과 형태),
  `concordance_flag`(척도-위기단계-정서 일치), `crisis_f3_gaps`(고위험인데 설문 미시행 세션).

## 2. 핵심 원칙

### 2.1 하나의 정보에는 하나의 주 위치만 둔다

같은 정보가 다음 영역에서 반복되지 않도록 한다.

- 현재 상태
- 주요 관찰
- 위험평가
- 임상 요약
- 종단 경과
- 다음 조치
- 상세 부록

권장 배치 원칙은 다음과 같다.

| 정보 유형 | 주 위치 |
|---|---|
| 현재 상태와 중증도 | 1페이지 |
| 현재 위험·안전평가 | 1페이지 |
| 주호소·현병력·관련 병력 | 2페이지 |
| 시간에 따른 변화 | 3페이지 |
| 다음 담당자 조치 | 4페이지 |
| 원문·전체 이력 | 선택형 부록 |

다른 위치에서는 동일 내용을 다시 작성하지 말고 `위험평가 참조`, `종단 경과 참조`처럼 연결만 한다.

### 2.2 기본 리포트와 감사 부록을 분리한다

하나의 PDF에 다음 세 가지 역할을 모두 넣지 않는다.

1. 임상 인계
2. 전체 세션 보존
3. AI·연구 분석 결과

권장 출력 형태:

- **Clinical Handoff View:** 기본 출력, 약 3~4페이지(종단 차트 1페이지 포함 기준)
- **Detailed Audit Appendix:** 요청 시 포함 — 같은 PDF에 이어 붙이면 총 페이지는 늘어나며,
  이는 중복만 없으면 문제로 보지 않는다(§2.3). 목표는 *Clinical View 부분*의 3~4페이지 유지.
- **Model/Research Output:** 임상 보고서와 별도 화면 또는 별도 문서

### 2.3 페이지 수보다 중복과 정보 위계를 먼저 줄인다

문서가 길게 느껴지는 주요 원인은 단순 페이지 수가 아니라 다음과 같다.

- 동일한 사실의 반복
- 임상 핵심지표와 보조지표의 동일한 강조
- 전체 이력을 기본 본문에 노출
- 빈 데이터 또는 평가 불가 항목을 고정 섹션으로 출력
- 기술·모델 정보가 사용자용 문서에 포함됨

## 3. 권장 기본 구성

## Page 1 — 현재 상태와 인계 우선순위

### 반드시 포함

- 환자 식별정보
- 최신 세션 및 평가 기준일
- 보고 기간 또는 세션 수
- 현재 위기 단계와 위험 수준
- 위기 반응 발생 여부
- 최신 주요 척도 점수와 시행일
- 자살사고 핵심 문항 결과
- 현재 상태 요약 2~4문장
- 즉시 확인할 조치 2~5개

### 현재 상태 요약 작성 규칙

현재 상태 문장에는 다음만 포함한다.

1. 현재 가장 중요한 증상 또는 문제
2. 최근 변화
3. 여전히 남아 있는 위험 또는 부담
4. 최신 위험·설문 핵심값

종단 전체 해석, 과거력, 상세 발화는 1페이지에서 제외한다.

### 예시

> 음주 빈도는 감소했으나 스트레스 상황의 갈망과 손 떨림 완화 목적의 음주가 지속된다. 최신 우울 척도는 중증 범위이며, 현재 자살사고 핵심 문항은 음성이다.

## Page 2 — 임상 요약

### 기본 항목

- 주호소
- 현병력
- 관련 신체 병력
- 정신과 과거력
- 음주·흡연·물질사용
- 사회적 상황과 지지체계
- 가족력 중 현재 판단과 관련 있는 내용
- 환자 직접 발화 1개
- 정신상태검사 제한 또는 관찰 가능 정보

### 항목 출력 조건

| 상태 | 처리 |
|---|---|
| 값이 있고 현재 판단에 직접 관련됨 | 본문 표시 |
| 값이 있으나 현재 관련성이 낮음 | 한 줄 요약 |
| 여러 세션 동안 변경 없음 | 최신값만 표시 |
| 값이 없음 | 섹션 숨김 |
| 평가 불가 | 필요한 경우 한 줄 안내 |
| 상세 원문이 중요함 | 대표 발화 1개만 본문, 나머지는 부록 |

### 주호소와 현병력 중복 처리

주호소와 현병력이 동일하거나 유사한 문장으로 생성되면 그대로 반복하지 않는다.

- **주호소:** 환자가 현재 가장 힘들다고 말하는 문제
- **현병력:** 시작 시점, 악화·완화 요인, 최근 경과, 기능 영향

구분이 어려우면 `현재 문제 및 경과`로 통합한다.

### 정신상태검사 처리

비대면 텍스트 문진에서 관찰 기반 평가가 불가능한 경우 독립된 큰 섹션으로 만들지 않는다.

권장 문구:

> 관찰 기반 정신상태검사는 비대면 텍스트 문진 특성상 평가가 제한됨.

## Page 3 — 종단 경과

### 반드시 포함

- 전체 경과 형태
- 핵심 지표별 변화
- 중요 세션 3~5개
- 핵심 임상지표 그래프
- 척도·위기단계·자가보고 간 불일치
- 고위험 세션에서 설문이 누락된 경우 경고

### 중요 세션 선택 규칙

전체 세션을 모두 나열하지 않고 다음을 우선한다.

- 최초 세션
- 가장 위험했던 세션
- 임상적으로 의미 있는 전환점
- 치료·생활 사건이 발생한 세션
- 최신 세션

동일한 상태가 반복된 세션은 하나로 묶는다.

### 종합 경과 표현

`개선`, `악화` 한 단어로만 표시하지 않는다.

권장 형식:

```text
종합 경과: 부분적 개선 / 혼합 경과 / 지속 악화 / 판단 제한

위기 단계      안정 방향
우울 증상      중증 범위 유지
음주 위험      고위험 범위 유지
기능 상태      변화 불명확
데이터 품질    핵심 슬롯 확인 완료
```

### 보조지표 처리

다음 지표는 임상 핵심지표와 같은 위계로 표시하지 않는다.

- 정서 극성
- 문진 항목 충족도
- AI 도메인 적합도
- 질환 유사도
- 모델 confidence

정서 극성과 문진 충족도는 기본 PDF에서 제거하거나, 유의미한 변화가 있을 때 한 줄 안내로만 표시한다.

### 각 조치에 필요한 필드

- 누가 담당할 것인가

- 근거가 된 세션 또는 데이터



### 상황 악화 시 대응

고위험 사례에서는 반드시 조건부 대응 문구를 포함한다.

예:

- 구체적 계획·의도 또는 수단 접근이 새롭게 확인되면 즉시 안전 경로 재평가
- 급격한 증상 악화 또는 연락 두절 시 지정 담당자에게 우선 전달
- 위기 단계가 기준 이하로 떨어지면 같은 날 임상 확인

## 5. 축약할 내용

### 5.1 위험 신호 전체 이력

본문에서는 다음 세 시점만 우선한다.

- 최초 위험
- 최고 위험
- 최신 위험

중간에 반복된 발화는 한 문장으로 묶는다.

예:

> S4·S7–S10에서 수동적 자살사고가 반복되었으며, 기록상 구체적 계획·의도는 일관되게 부인함.

전체 발화 전문은 감사 부록으로 이동한다.

### 5.2 문항별 설문 응답

본문에는 다음만 남긴다.

```text
PHQ-9 21/27 · 중증 범위
시행: 10회차, 2027-01-14
9번 문항: 0점 · 음성
```

다음은 부록 또는 상세보기로 이동한다.

- 전체 문항별 점수
- 응답 척도 설명
- 문항은행 버전
- 출처 상세
- 시행 방식 상세

### 5.3 슬롯별 변화 이력

본문에는 최신값과 임상적으로 의미 있는 변화만 표시한다.

- 변경 없는 슬롯: 최신값만
- 표현만 달라진 반복 세션: 삭제
- 임상적 변화가 있는 세션: 타임라인에 포함
- 전체 슬롯 이력: 선택형 부록

### 5.4 환자 직접 발화

- 현재 상태를 가장 잘 설명하는 발화 1개
- 위험평가에서 필요한 발화 1개
- 동일한 의미의 발화 반복 금지
- 긴 발화는 의미가 유지되는 범위에서 2~4줄로 제한

## 6. 기본 Clinical View(본문)에서 뺄 내용

아래 항목은 **기본 임상 본문에서 제거**한다. 다만 "제거"는 대부분 *다른 위계로 이동*을
뜻하며, 완전 삭제와 구분한다. 이동 대상은 §8의 Audit Appendix / Internal Research View 참조.

### → Audit Appendix(참고·요청 시)로 이동

- 슬롯 전체 변경 이력
- 세션별 위험 발화 전문 · 반복 환자 발화 전문
- 문항별 설문 응답 전체 · 문항은행 버전 · 시행 방식 상세
- caveat 원문
- **질환 유사도 순위(최신 스냅샷) — 참고·비진단으로만**

### → Internal Research View(임상 PDF와 별도)로 이동

- 질환 유사도 **점수 시계열·추세 차트**
- 도메인 confidence 시계열 · 모델 confidence
- 정서 극성 전체 그래프 · 문진 충족도 전체 그래프(유의미한 변화만 본문 한 줄)
- 전체 세션 turn 로그 · RAG 검색 메타 · 오류/validation 기록

### → 완전 삭제(사용자 문서에 불필요)

- 이미지 파일명 · 코드명·함수명·변수명
- LLM 모델명 · 프롬프트 버전 · 내부 문서 버전
- 토큰 사용량 · latency·retry·validation telemetry
- 빈 섹션 · 반복 면책 문구(면책은 문서 말미 1회)

### AI 질환 후보 처리 원칙 (3단 위계)

1. **기본 Clinical View 본문**: 질환 순위·유사도 점수를 노출하지 않는다. 대신 평가 영역만 제시.

   ```text
   추가 평가 영역
   - 음주 사용 및 금단 관련 증상
   - 우울 증상
   - 자살 위험
   - 신체질환 및 복약 상태
   ```

2. **Audit Appendix**: 최신 세션 기준 **질환 유사도 순위**를 `참고 · 비진단`으로 표기해
   노출할 수 있다. `similarity_score`는 **확률·가능성·진단이 아님**을 캡션에 명시하고,
   진료과 후보 등 스케일이 다른 지표와 한 축에 섞지 않는다.
3. **Internal Research View**: 유사도/도메인 **시계열·추세·confidence**와 모델 정보는 여기서만.

> (NeuroSync 현행 구현: 부록에 질환 유사도 순위만 노출, 추세 차트(FIG.03)는 제거 — 위 원칙과 일치.)

## 7. 조건부로 추가할 내용

### 7.1 고위험 사례

다음 구조를 추가한다.

```text
자살사고       있음 / 없음
최근성·빈도    현재 / 최근 / 간헐적 / 지속적
계획           있음 / 없음 / 미확인
의도           있음 / 없음 / 미확인
수단 접근      있음 / 없음 / 미확인
과거 행동      있음 / 없음 / 미확인
위험요인       ...
보호요인       ...
현재 위험수준  ...
대응계획       ...
```

값이 없으면 추론해 채우지 않고 `미확인`으로 표시한다.

### 7.2 음주·금단 의심 사례

다음 필드를 우선 수집·표시한다. (해당 시 **AUDIT-C 총점·심각도**를 최신 설문에 함께 노출)

- AUDIT-C 총점 / 심각도 및 시행일(있는 경우)
- 마지막 음주 시점
- 최근 평균 음주량과 빈도
- 감량·중단 이후 증상 발생 시점
- 과거 금단, 발작 또는 섬망 이력
- 현재 손 떨림 외 동반 증상
- 간 기능 검사일과 실제 결과
- 현재 복용약
- 음주 후 증상 완화 여부

### 7.3 복약·알레르기 관련

데이터가 존재할 때만 표시한다.

- 현재 복용약
- 복용 중단 또는 순응도 문제
- 최근 변경약
- 알레르기·이상반응
- 약물명·용량·복용 시점
- 약물과 현재 증상의 관련 가능성

`구조화된 약물 정보 없음`만 단독으로 표시하지 않는다.

복약 중단 또는 불명확한 언급이 있으면 다음처럼 바꾼다.

> 고혈압 약 복용 중단 상태 — 약물명·용량·중단 시점 확인 필요

### 7.4 데이터 품질 이슈

다음 상황에서만 본문에 표시한다.

- 고위험인데 설문 미시행
- 최신 설문이 오래됨
- 척도와 위기단계가 불일치
- 핵심 슬롯이 미완성
- 위험 발화와 구조화된 라벨이 충돌
- 환자 발화와 AI 요약이 모순됨

## 8. 기본 Clinical View와 Audit View 분리

## 8.1 Clinical View

기본 3~4페이지.

포함:

1. 현재 상태
2. 위험·안전
3. 주호소·현병력·관련 병력

5. 종단 경과
6. 다음 조치
7. 상황 악화 시 대응

## 8.2 Audit Appendix

요청 시 생성.

포함:

- 슬롯별 전체 변화 이력
- 세션별 위험 발화
- 설문 전체 문항 점수
- 세션별 데이터 출처
- 최신값 provenance
- 데이터 최신성
- caveat 원문
- 추출·요약 전 원문
- 질환 유사도 순위(최신 스냅샷 · 참고·비진단)

## 8.3 Internal Research View

임상 PDF와 별도.

포함:

- 질환 유사도 **시계열·추세 차트**(순위 스냅샷은 Audit Appendix)
- 도메인 적합도(confidence) 시계열
- 모델 confidence
- 모델·프롬프트 정보
- RAG 검색 메타
- 오류·validation 기록
- latency·usage·retry
- 상세 데이터 품질 지표

## 10. 문서 생성 규칙

### 10.1 빈 섹션 자동 숨김

다음 경우 섹션을 출력하지 않는다.

- 값이 없음
- 구조화 데이터가 없음
- 모든 값이 `미확인`
- 임상 판단에 영향을 주지 않는 내부 정보뿐임

### 10.2 길이 제한

- 현재 상태: 2~4문장
- 주호소: 1~2문장
- 현병력: 3~6문장
- 각 보조 병력: 1~2문장
- 대표 발화: 최대 4줄
- 주요 관찰: 최대 4개
- 다음 조치: 최대 5개
- 중요 세션: 최대 5개

### 10.3 중복 감지

다음 항목 간 의미 유사도가 높으면 병합한다.

- 현재 상태 ↔ 주호소
- 주호소 ↔ 현병력
- 주요 관찰 ↔ 인계 중점
- 권장 진료 ↔ 조치 사항
- 위험 신호 경과 ↔ 슬롯 전체 위험 이력
- 주요 세션 ↔ 전체 슬롯 변화 이력

### 10.4 최신값과 과거값 구분

- 본문: 최신값 중심
- 종단 페이지: 중요한 변화 중심
- 부록: 전체 이력
- 최신값이 이전 세션에서 이월된 경우 출처 세션 표시
- 최신 설문이 당해 세션에서 시행되지 않았으면 `직전 시행`과 날짜 표시

## 13. 최종 검수 체크리스트

### 내용

- [ ] 현재 위험과 최신 평가일이 한눈에 보이는가
- [ ] 주호소와 현병력이 중복되지 않는가
- [ ] 최신 설문과 이전 설문이 구분되는가
- [ ] 자살사고 핵심 문항이 명확한가
- [ ] 위험 발화와 구조화된 라벨이 일치하는가
- [ ] 각 조치에 담당과 시점이 있는가
- [ ] 종단 경과가 단순 다수결로 과도하게 축약되지 않았는가
- [ ] 데이터 품질을 임상 호전으로 표현하지 않았는가
- [ ] 미확인 값을 추론해서 채우지 않았는가

### 분량

- [ ] 기본 본문이 3~4페이지 내외인가
- [ ] 전체 슬롯 이력이 기본 본문에서 빠졌는가
- [ ] 중간 세션의 반복 발화가 묶였는가
- [ ] 문항별 설문 응답이 필요할 때만 노출되는가
- [ ] 빈 섹션이 자동으로 숨겨지는가

### 사용자용 표현

- [ ] 모델명·프롬프트·변수명이 노출되지 않는가
- [ ] `confidence`를 확률처럼 표현하지 않았는가
- [ ] 질환 후보를 진단처럼 강조하지 않았는가
- [ ] 정서 극성을 임상 척도로 오인하게 하지 않는가
- [ ] 문진 충족도를 증상 개선처럼 표시하지 않는가
- [ ] 영어 업무 메타데이터가 과도하게 반복되지 않는가

### 부록

- [ ] 전체 이력은 선택형 부록으로 분리됐는가
- [ ] 부록에도 환자 식별정보와 페이지 번호가 있는가
- [ ] 원문과 요약이 명확히 구분되는가
- [ ] 기술 감사 정보는 임상 부록과 분리됐는가

## 15. 최종 권장 원칙 요약

1. 기본 보고서는 현재 상태, 위험, 임상 요약, 종단 변화, 다음 조치만 포함한다.
2. 같은 정보는 한 번만 상세히 작성한다.
3. 전체 변화 이력과 발화 전문은 선택형 부록으로 분리한다.
4. AI 질환 후보는 기본 본문에서 빼고(부록에 `참고·비진단` 순위만 허용), 기술·모델 정보는 의료진용 보고서에서 완전히 제거한다.
5. 고위험 사례는 위험정보를 더 길게 쓰는 대신 구조화한다.
6. 정서·문진 완성도는 임상 핵심지표와 분리한다.
7. `개선/악화` 한 단어보다 지표별 상태를 우선한다.
8. 조치에는 반드시 담당과 시점을 포함한다.
9. 데이터가 없거나 평가 불가인 섹션은 숨긴다.
10. 기본 Clinical View와 Audit View를 분리해 길이와 추적 가능성을 동시에 확보한다.
