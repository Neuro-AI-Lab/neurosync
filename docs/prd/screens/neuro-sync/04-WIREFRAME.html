Legend & conventions

This is a lo-fi clickable wireframe for stakeholder review. Layout, microcopy and information hierarchy reflect 03-SCREEN-SPEC.md. Visual style (brand color, typography, motion) is intentionally deferred to a later mockup step.

  • Each phone frame is 375 × 812 pt and is independently scrollable.
  • Click a frame to focus / highlight it. Use the sticky top-nav (or any in-screen link) to jump between screens.
  • Korean microcopy is taken verbatim from the screen spec. Icons (🏠 🏥 ⚙ 🎤 📞 🚑 ⚠️ ↑ ← ▾) act as placeholders, mirroring the spec.
  • HTML comments (<!-- a11y: ... -->) annotate key interactive elements with intended roles / labels.
  • Recording overlay, streaming cursor and risk banner are the only animated elements. No marketing motion.
