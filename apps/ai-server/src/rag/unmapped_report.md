# 미매핑 보고 — Ada 증상 중 어떤 플래그에도 안 붙은 것

> 심리상담 플래그(우울/불안/중독 중심)로 Ada 26질환 증상을 매핑한 결과.

> 매핑 엣지 169개 / **미매핑 35건**. 아래는 플래그 어휘로 표현 불가한 증상.


## 핵심 패턴

- **우울/불안/중독 계열**: 거의 완전 매핑 (플래그 기원과 일치).
- **정신병(환각·망상)·조증·신경발달(자폐/ADHD)·치매·신경학(전환장애)·신체 특이증상**: 대거 미매핑.
- → 이 영역은 case_card 플래그만으론 표현 불가. Ada description/QA로 보완하거나, 필요 시 신규 증상 플래그 추가 검토.


## 질병별 미매핑 목록

- **월경전 불쾌장애** (`premenstrual-dysphoric-disorder-pmdd`): 유방 압통, 복부팽만, 설사, 손발 부종
- **급성 공황발작** (`acute-panic-attack`): 죽음에 대한 공포
- **공황발작 징후** (`signs-of-panic-attack`): 무력감
- **적응장애** (`adjustment-disorder`): 사회·직업 기능 저하
- **태아 알코올 스펙트럼 장애** (`fetal-alcohol-spectrum-disorders`): 안면 기형, 저성장, 소두증, 발달 지연, 지적장애
- **알코올 중독(급성)** (`alcohol-intoxication`): 운동실조, 발음 어눌, 혼수, 호흡부전
- **알코올 금단** (`alcohol-withdrawal`): 경련, 진전섬망
- **전환장애** (`conversion-disorder`): 실명, 마비/위약, 발작, 감각 상실, 발성불능, 운동틱, 가성임신
- **알츠하이머병** (`alzheimers-disease`): 배회, 시공간 장애, 요실금, 발작, 실행기능 상실
- **루이소체 치매** (`dementia-with-lewy-bodies`): 파킨슨증(떨림·경직), 인지 변동, 자율신경 이상, 실금
- **HIV 치매** (`hiv-dementia`): 언어 느림
